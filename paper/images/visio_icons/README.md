# DA-CPSL Visio SVG Icons

这些图标是根据 `Overview of DA-CPSL.png` 中的基础视觉元素重画的可编辑 SVG，不是从 PNG 中直接裁剪出来的位图片段。

建议用法：

1. 在 Visio 中选择 `插入` -> `图片` -> `此设备`。
2. 选择本目录下的某个 `.svg` 文件。
3. 如需进一步编辑，尝试右键 SVG 后使用 Visio 的 `转换为形状` / `取消组合` 功能。不同 Visio 版本的菜单名称可能略有差异。

图标清单：

- `attacker_laptop.svg`：红色攻击者加笔记本。
- `defender_laptop.svg`：蓝色防御者加笔记本。
- `cloud.svg`：云端/外部网络。
- `network_router.svg`：中心网络/路由节点。
- `server.svg`：服务器。
- `database_asset.svg`：数据库/关键资产。
- `shield_check.svg`：可部署/安全有效。
- `shield_alert.svg`：关键资产安全/风险提示。
- `business_growth.svg`：业务连续性/增长。
- `defense_cost.svg`：防御成本。
- `people_group.svg`：初始偏好采样人群。
- `brain_policy.svg`：策略训练。
- `sliders_limits.svg`：硬约束/操作限制。
- `operator_user.svg`：操作员偏好。
- `balance_scale.svg`：效用选择。
- `warning_triangle.svg`：不可行分配。
- `pareto_scatter.svg`：Pareto 散点集合。
- `mini_bar_chart.svg`：候选策略/目标返回柱状图。
